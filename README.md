# 🏸 SMASHPRO Badminton HQ — Full-Stack E-Commerce Platform

> The ultimate digital store & stringing customizer studio for tournament-grade badminton weapons (Yonex, Victor, Li-Ning, Mizuno, Apacs).

## ⚡ Core Features

- 🎯 **High-Performance Racket Catalog**: 12 elite tournament models with complete technical specifications (balance point, shaft stiffness, weight class 3U/4U/5U, max string tension limit up to 38 lbs, and player endorsements).
- 🛠️ **Interactive Custom Stringing Studio**: Custom string selection (*BG80 Power, BG65Ti, Exbolt 65, Aerobite Hybrid, Li-Ning No.1, Victor VBS-66*), electronic tension calibration slider (**20–34 LBS**), stencil logo applicator, and overgrip wrap color picker.
- 🧬 **Dynamic 5-Axis Performance DNA Radar**: Interactive SVG radar matrix measuring *Power Smash*, *Speed Reflex*, *Control Pinpoint*, *Frame Durability*, and *Sweet Spot Forgiveness*.
- 🤖 **Smart Racket Matchmaker Quiz**: 4-step algorithm analyzing player skill level, court position, wrist speed, and offensive style to output tailored percentage-matched recommendations.
- ⚖️ **Side-by-Side Spec Comparison Matrix**: Compare up to 4 tournament rackets simultaneously.
- 🛒 **Workshop Cart & Multi-Step Checkout**: Promo discount vouchers (`SMASH20`, `PROBADMINTON`, `FREESHIP`), simulated payment gateway (Cards, Apple Pay, UPI/QR), and instant digital receipt generator.
- 📦 **Live Stringing Studio & Courier Tracker**: Real-time order progress timeline tracking tension calibration and delivery dispatch.
- 📊 **Admin Management Portal**: Real-time KPI cards (Revenue, Orders, Stock Alerts), inline inventory editor, and order step advancement controls.

## 🏗️ Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS, Lucide React Icons, SVG Dynamic Charts
- **Backend**: Node.js, Express REST API, CORS
- **Data Persistence**: JSON-backed local storage store with auto-seeding

## 🚀 Getting Started

### 1. Prerequisites
- Node.js (v18+)
- npm (v9+)

### 2. Backend Server Setup
```bash
cd server
npm install
npm run dev
# Express API server starts on http://localhost:5000
```

### 3. Frontend Client Setup
```bash
cd client
npm install
npm run dev
# Vite dev server starts on http://localhost:3000
```
